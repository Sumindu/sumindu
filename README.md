## 👨‍💻 About Me

I'm a **Software Engineer from Sri Lanka** working on **backend development, process automation and production systems** in the financial services sector. I hold a **BSc (Hons) in Data Science** (Upper Second Class, London Metropolitan University, 2025) and an **HND in Software Engineering** (Merit).

- ⚙️ I build **automation that runs unattended**: scheduled jobs, API integrations and messaging pipelines with full audit trails
- 🛠️ Main stack: **Node.js / Express, Python and MS SQL Server**, with **React + TypeScript** on the frontend
- 🚀 I deploy and run my own apps on **Linux VPS (DigitalOcean)** with **Nginx, PM2, Certbot and Cloudflare**
- 🧠 Interested in **machine learning and big data** (scikit-learn, PySpark, Kafka)

## 🏷️ Software for Sale

### 📦 Distribution Sales & Collection Management System

Web system for **distributors and wholesalers** who sell on credit to retail shops and collect payments in the field. It's already running in production for real businesses and is **available for licensing**, with setup and customisation for your business.

<table>
  <tr>
    <td width="50%" valign="top">
      <h4>🧑‍💼 For the office (admin)</h4>
      <ul>
        <li><b>Business dashboard</b>: revenue, outstanding, overdue, cash-flow health and 6-month trends</li>
        <li><b>Shop / customer management</b> with payment terms, outstanding balances and payment status</li>
        <li><b>Transfer orders &amp; invoicing</b> per shop and product</li>
        <li><b>Cheque management</b>: track pending cheques until they clear</li>
        <li><b>Receipt approval workflow</b> for payments collected in the field</li>
        <li><b>Reports</b> exported to <b>PDF and Excel</b></li>
      </ul>
    </td>
    <td width="50%" valign="top">
      <h4>🛵 For field collectors</h4>
      <ul>
        <li><b>Installable mobile app (PWA)</b> that works on any phone</li>
        <li>Only sees the shops assigned to them</li>
        <li>Record cash, cheque and bank-transfer payments on the spot</li>
      </ul>
      <h4>🔒 Behind the scenes</h4>
      <ul>
        <li><b>Role-based access</b> (admin / collector) with JWT authentication</li>
        <li><b>Automatic FIFO payment reconciliation</b> against the oldest invoices</li>
        <li><b>Nightly automated database backups</b></li>
        <li>Supports <b>multiple businesses</b>, each with its own database</li>
      </ul>
    </td>
  </tr>
</table>
